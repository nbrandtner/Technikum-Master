# AR Ski Goggles

## 3 Excitement Requirements:

### Manual Method

REQ-01 - **Combination**: AR + Zeitrennen/Ghost-Modus + Leaderboard
As a frequent skier, I can see ghosts of mine and my friends fastest runs to race against and set high scores on leaderboards.

REQ-02 - **Variation**: Kollisionswarnsystem aus Autos oder Fahrrädern auf das Skifahren übertragen
As a beginner skier, I receive a visual warning when another skier or snowboarder approaches rapidly from behind and creates a collision risk, so that I can react in time and avoid a collision.

REQ-03 - **Combination**: AR + Gamification
As a recreational skier, I can activate an augmented-reality challenge that displays virtual rings along the piste and awards more points the closer I pass to the center of each ring, so that I can make my runs more entertaining and improve my skiing precision.

### First AI Try with simple prompt

Prompt: `please make 3 requirements for ar skiing goggles`

Result: 

```
Real-Time Navigation
The goggles shall display AR navigation information, such as the direction to selected ski lifts, slopes, or destinations, directly in the user's field of view.

Speed and Skiing Information
The goggles shall display real-time information such as the skier's current speed, altitude, and distance travelled.

Safety Warnings
The goggles shall warn the skier about relevant hazards, such as closed slopes, dangerous areas, or approaching bad weather, without significantly obstructing their vision.
```

### Second Try with enhanced prompt

Prompt: `I am designing augmented reality skiing goggles. Generate at least three new and exciting feature requirements for these goggles. Use the creativity methods Combination, Variation, and Inversion from Requirements Engineering. The features should go beyond basic functionality and should be realistic enough to be implemented in AR skiing goggles. For each feature, briefly state which creativity method was used and formulate the result as a clear requirement. Avoid features that are already standard in existing skiing goggles.`

Result:

| Method          | Idea                                                         | Requirement                                                  |
| --------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **Combination** | **AR + Emergency Detection** — Combine AR goggles with crash detection and emergency communication. | **The goggles shall detect a possible crash using motion sensors and display an emergency prompt that allows the skier to contact ski patrol and share their location.** |
| **Variation**   | **Adaptive AR Interface** — Instead of always showing the same information, vary the interface depending on the skier's situation. | **The goggles shall automatically reduce non-essential AR information when the skier is travelling at high speed and restore it when the skier slows down or stops.** |
| **Inversion**   | **Whiteout Assistance** — Normally, poor visibility makes skiing harder; turn this problem around by using the goggles to improve orientation. | **The goggles shall detect low-visibility conditions and display an AR representation of the slope direction and marked piste boundaries to help the skier maintain orientation.** |
