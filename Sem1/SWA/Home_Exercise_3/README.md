# MateMate Home Exercises

## 1. Unearth Your Solutions

Reconstructed a MateMate architecture proposal from the course brief. The design divides the chess app into seven subsystems and maps the class’s service list to them. The walkthroughs show how a drag from e2 to e4 becomes a legal move, how the computer calculates and displays its reply, and how the rules track castling rights for both colors.

[Architecture proposal](01_Unearth_Your_Solutions/MateMate_Architecture_Proposal.pdf)

## 2. Architectural Frameworks

Created a review framework using three C4 views and selected arc42 sections, then applied it to the same MateMate design. It adds three review records that identify who can change critical state, define which components a proposed change may touch, and track when verification evidence needs to be refreshed. The diagrams use color, borders and size to show component roles, state ownership and review priority. The scorecard reports design-level checks and leaves runtime measurements pending implementation.

[Framework and MateMate example](02_Architectural_Frameworks/Architecture_Review_Framework_MateMate.pdf)
