# EarlyBird Architecture

Three independent solutions to the EarlyBird application core architecture exercise.

- **01_Simple**: concise components, order flow, and the three requirement changes.
- **02_Standard**: modular architecture, business rules, order submission sequence, and change impacts.
- **03_Detailed**: detailed contracts, domain model, consistency rules, failure handling, requirement coverage, and validation scenarios.

Each version contains a PDF, an editable Markdown document, and a diagrams folder. Diagrams are provided as SVG and PNG images and editable Mermaid source files with the .mmd extension.
